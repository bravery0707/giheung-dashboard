# 힐스테이트 기흥 데이터랩

공개 GitHub Pages에서는 국토교통부 실거래를 보고, 매물 원본과 일별 관측 이력은 개인 PC에서 분석합니다. 개인 화면은 이 PC의 `127.0.0.1`에만 열립니다.

## 현재 상태

**비공개 저장·요청 제한·중단 처리 구현 / 실제 네이버 자동 수집 경로 미연결.**

이 프로그램의 수집기는 정해진 JSON 피드 연결부입니다. 네이버 페이지를 직접 읽는 수집기는 아직 없으며, 웹 주소를 설정에 넣는 것만으로 작동하지 않습니다. 브라우저에서 네이버 매물 화면이 열리는 것을 확인한 결과와 자동 수집 성공은 구분합니다. 네이버 문의 메일은 보내지 않았습니다.

## 개인 화면 열기

Node.js 22 이상에서 저장소 폴더를 열고 실행합니다.

```sh
node scripts/private-dashboard.mjs
```

브라우저에서 `http://127.0.0.1:8787/#listings`를 엽니다. 새로고침은 저장된 자료만 읽습니다. 매물 원본·이력·실패 상태·요청 제한 기록은 Git에서 제외된 `.private/listing-data/`에 저장하며, 수집 설정은 `.private/source.json`에 둡니다. 로컬 저장은 암호화나 Windows 사용자 간 접근 통제를 제공하지 않으므로 이 PC 계정과 백업의 접근 권한은 별도입니다.

기존 조사 파일을 가져올 때는 실제 조사일을 지정합니다.

```sh
node scripts/import-listings.mjs "C:/자료/매물.xlsx" --date 2026-09-01
```

이는 기존 자료 이전용입니다. 엑셀의 매물 확인일을 조사일로 사용하지 않습니다. 같은 조사일 교체는 `--replace-date`, 전체 건수를 확인한 급감 자료 반영은 `--accept-count-drop`이 필요합니다. 공개 `data/`나 `incoming/`에 원본을 올리지 않습니다.

## 요청 제한과 예약

연결 가능한 JSON 피드가 준비되면 [설정 문서](docs/listing-automation.md)를 따라 로컬 설정을 채웁니다.

- 한국시간 하루 최대 1회 GET. 실패·재시작·동시 실행에도 추가 요청을 보내지 않습니다.
- 30초 제한, 5 MiB 응답 제한, 자동 재시도와 리디렉션 추적 없음.
- 401·403·429·리디렉션·HTML/비JSON 응답은 지속 중지. 날짜가 바뀌어도 수동 재개 전에는 요청하지 않습니다.
- 부분 수집·급격한 건수 감소·잘못된 ID·날짜는 반영하지 않고 이전 정상 자료를 유지합니다.
- 시험 기간은 최대 14일이며 자동 연장하지 않습니다.

`node scripts/private-dashboard.mjs --schedule`은 한국시간 21:10 이후 하루 한 번 실행합니다. PC와 프로그램이 켜져 있어야 하며, 꺼져 있던 날의 누락은 새 관측으로 채우지 않습니다. 실제 제공처가 미설정이면 예약 실행도 시작하지 않습니다.

## 공개 배포와 검증

```sh
node --test tests/*.test.mjs
node scripts/build-public.mjs
node scripts/private-dashboard.mjs --public
```

공개 빌드는 HTML·정해진 assets·실거래 JSON·비공개 안내용 빈 매물 JSON만 담습니다. 매물 업로드/수집용 GitHub Actions는 읽기 전용 검사로 바꿨습니다. 실거래 자동 갱신은 기존대로 한국시간 08:30입니다. Pages Source는 GitHub Actions를 사용합니다.

현재 커밋에서 자료를 제거해도 **과거 Git 커밋·이전 PR·이미 내려받은 사본은 지워지지 않습니다.** `.gitignore`와 빌드 검사는 과거 공개 이력을 숨기는 기능이 아닙니다. 이력 삭제는 별도 작업입니다.

매물 소멸은 거래 완료가 아닙니다. 신규·가격변동·재등장·지속 소멸 후보는 정상 조사일 사이의 광고 관측 결과입니다. 모의 응답으로 통과한 검증을 실제 네이버 수집이나 14일 운영 실적으로 표시하지 않습니다.
