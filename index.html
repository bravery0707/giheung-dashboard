지속 소멸 후보

사라진 뒤 후속 스냅샷에도 다시 나타나지 않은 매물

매물 엑셀 갱신 방법업로드 한 번으로 JSON 변환·변동 기록열기
  1. Edge의 Tampermonkey 버튼으로 힐스테이트 기흥 엑셀을 내려받습니다.
  2. 저장소의 incoming/listings.xlsx에 같은 이름으로 업로드합니다.
  3. GitHub Actions가 자동으로 매물·변동 JSON을 만들고 원본 엑셀은 현재 브랜치에서 제거합니다.

하루 단위 변동이 필요하면 하루 한 번 스냅샷이 필요합니다. PC가 꺼져 있으면 Edge 확장프로그램은 실행되지 않으며, 네이버 내부 API를 GitHub 서버에서 무인 수집하는 방식은 사용하지 않습니다.

공개자료를 정리한 참고용 대시보드입니다. 호가 소멸은 실거래 확정 신호가 아니며 계약 전 등기·중개사·신고자료를 교차 확인하세요.
