    매일 자동 갱신 — GitHub Actions (권장)

    인증키는 계정당 하나입니다. 이미 받으셨다면 새 키를 또 받을 필요 없이, 아래 API에 활용신청만 추가하면 같은 키로 호출됩니다(자동 승인).

    API필요도없으면
    아파트 매매 실거래가 자료 보유 중매매 차트·테이블의 기본 소스
    아파트 전월세 실거래가 자료 추가 권장전세·월세 추이와 실거래 기준 전세가율이 비어 있음
    아파트 매매 실거래가 상세 자료 선택동(棟)·등기일자가 빠져 매물의 동별 비교가 안 됨

    수집 스크립트는 상세 자료 → 기본 자료 순으로 시도하고, 신청하지 않은 API는 자동으로 건너뛴 뒤 어떤 소스를 썼는지 로그와 data/transactions.json에 남깁니다. 지금 상태로도 매매는 정상 수집됩니다.

    1. 저장소 Settings → Secrets and variables → Actions에 DATA_GO_KR_KEY로 Decoding 키 등록
    2. 푸시하면 매일 새벽 data/transactions.json이 갱신됩니다

    apis.data.go.kr은 CORS 헤더를 주지 않아 정적 페이지에서 직접 fetch할 수 없습니다. 수집은 Actions에서, 페이지는 결과 JSON만 읽는 구조라 페이지에 키를 심지 않아도 됩니다.

    export DATA_GO_KR_KEY="발급받은_디코딩_키"
node scripts/update.mjs --months 36

    출처와 기준일
    개인 참고용 정리 도구입니다. 시세·세액·수익률은 공개 자료를 바탕으로 한 추정치이며 실제 거래·신고 금액과 다를 수 있습니다. 투자 판단과 결과는 이용자 본인의 책임이며, 계약 전에는 등기부등본·관리비·중개사 확인을 거치시기 바랍니다. 토지거래허가구역 내 아파트 매수는 관할 구청 허가가 선행되어야 합니다.
